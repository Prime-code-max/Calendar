# Admin Frontend

React приложение для административной панели календарного приложения.

## Функциональность

- **Статистика**: Визуализация общей статистики системы
- **Управление пользователями**: Просмотр, редактирование, удаление пользователей
- **Управление событиями**: Просмотр, редактирование, удаление событий

## Доступ

Админка доступна по адресу: `http://localhost:8080/admin`

## Использование

1. Войдите с учетными данными администратора (username должен совпадать с `ADMIN_USERNAME` из .env)
2. Используйте вкладки для навигации:
   - **Статистика**: Обзор системы
   - **Пользователи**: Управление пользователями
   - **События**: Управление событиями

## Разработка

```bash
npm install
npm start
```

Приложение будет доступно на `http://localhost:3000`

## Сборка

```bash
npm run build
```

Собранные файлы будут в директории `build/`.
