# Инструкция по входу в админку

## Шаг 1: Создайте пользователя-администратора

По умолчанию администратором считается пользователь с именем `admin`. Вы можете изменить это в `.env` файле, добавив:
```
ADMIN_USERNAME=ваше_имя
```

### Вариант 1: Через основной фронтенд (рекомендуется)

1. Откройте основной сайт: http://localhost:8080
2. Зарегистрируйте нового пользователя с именем `admin` (или тем, что указано в `ADMIN_USERNAME`)
3. Запомните пароль

### Вариант 2: Через API напрямую

Выполните команду в PowerShell:

```powershell
$body = @{
    username = "admin"
    password = "ваш_пароль"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8080/api/register" -Method POST -Body $body -ContentType "application/json"
```

Или через curl (если установлен):
```bash
curl -X POST http://localhost:8080/api/register -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"ваш_пароль\"}"
```

## Шаг 2: Войдите в админку

1. Откройте в браузере: **http://localhost:8080/admin**
2. Введите:
   - **Username**: `admin` (или ваше имя администратора)
   - **Password**: пароль, который вы указали при регистрации
3. Нажмите "Войти"

## Шаг 3: Используйте админку

После входа вы увидите три вкладки:
- **Статистика** - общая статистика системы
- **Пользователи** - управление пользователями
- **События** - управление событиями

## Важно!

- Имя пользователя должно точно совпадать с `ADMIN_USERNAME` из `.env` (по умолчанию: `admin`)
- Если вы уже создали пользователя с другим именем, вы можете либо:
  1. Изменить `ADMIN_USERNAME` в `.env` на имя существующего пользователя
  2. Или создать нового пользователя с именем `admin`
