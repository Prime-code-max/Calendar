# Admin Service

Микросервис для административной панели календарного приложения.

## Функциональность

- **Статистика**: Общая статистика системы (пользователи, события, активность)
- **Управление пользователями**: Просмотр, редактирование, удаление пользователей
- **Управление событиями**: Просмотр, редактирование, удаление событий всех пользователей

## API Endpoints

### Статистика
- `GET /admin-api/stats` - Получение статистики системы

### Пользователи
- `GET /admin-api/users` - Список пользователей (с пагинацией)
- `GET /admin-api/users/{user_id}` - Получение пользователя по ID
- `PUT /admin-api/users/{user_id}` - Обновление пользователя
- `DELETE /admin-api/users/{user_id}` - Удаление пользователя

### События
- `GET /admin-api/events` - Список событий (с пагинацией и фильтрацией)
- `GET /admin-api/events/{event_id}` - Получение события по ID
- `PUT /admin-api/events/{event_id}` - Обновление события
- `DELETE /admin-api/events/{event_id}` - Удаление события

## Аутентификация

Все эндпоинты требуют JWT токен в заголовке `Authorization: Bearer <token>`.

Для доступа к админке необходимо:
1. Войти через обычный `/api/token` эндпоинт с учетными данными администратора
2. Использовать полученный токен для доступа к админским эндпоинтам

Администратор определяется через переменную окружения `ADMIN_USERNAME` (по умолчанию: `admin`).

## Переменные окружения

- `DATABASE_URL` - URL подключения к базе данных PostgreSQL
- `SECRET_KEY` - Секретный ключ для JWT токенов (должен совпадать с auth-service)
- `ADMIN_USERNAME` - Имя пользователя администратора (по умолчанию: `admin`)
